# 追加課題：スキルを 1 つ導入する

任意・終了後または早く終えた方向けに 5〜10 分

必須の 2 題は、この追加課題を行わなくても完了です。ここでは、課題 1 のアシスタントのシナリオに使う `agent` スキルを調べ、適していればインストールします。知識や手順を追加することは、エージェントや製品をデプロイすること、ソリューションの動作を証明することとは異なります。

!!! note "取得できることを確認したパッケージを使う"
    2026 年 9 月 10 日には、公式の生成済み `agent` アーカイブを取得でき、`agent/SKILL.md` が含まれることを確認しました。他のスキルには、カタログの配布リンクが 404 になるものもありました。実行時の結果を確認し、失敗した場合は記録して、この追加課題を止めます。

## ステップ 1：承認する前に内容を確認する

Explorer の新しい会話へ貼り付けます。

```text
架空の文書アシスタントのシナリオに向けて、get_skill と download_skill を使い、
agent スキルを調べてください。目的、公式のダウンロード URL、前提条件、
ワークスペースに追加されるファイルを示してください。
まだインストールしないでください。モードの追加、製品の設定、デプロイもしません。
```

説明を読み、このアシスタントのシナリオに役立つか確認します。取得元は公式の `ibm-self-serve-assets/building-blocks` リポジトリであることを確認してください。URL が表示されたことだけでは、ダウンロード成功の証拠にはなりません。

## ステップ 2：選んだスキルだけを導入する

内容と範囲を確認し、進めてよければ指示します。

```text
確認した公式の URL から、この演習用ワークスペースへ agent スキルだけを
インストールしてください。モードや他のスキルの導入、サービスの設定、
デプロイは行わないでください。インストーラーを使い、検証結果を報告してください。
```

期待される保存先は `.bob/skills/agent/` で、中に `SKILL.md` があります。インストーラーの結果とファイルを確認します。その後、Explorer の公式ガイドに従って Bob を再読み込みします。

=== "macOS"

    必要なら Finder の `Command` + `Shift` + `.` で隠しフォルダを表示します。Bob のファイル一覧で `.bob/skills/agent/SKILL.md` を確認しても構いません。

=== "Windows"

    必要ならエクスプローラーの「表示」→「表示」→「隠しファイル」を使います。Bob のファイル一覧で `.bob/skills/agent/SKILL.md` を確認しても構いません。

## ステップ 3：違いを記録する

Explorer が行ったこと、インストールされたもの、エンジニアによる作業が必要なことを、1 文ずつ記録します。失敗した場合は実際のエラーを残し、成功したと報告しません。

- [ ] 承認前に、目的、出典、導入範囲を確認した。
- [ ] 導入後のファイルと結果を確認した。または、中断した理由を記録した。
- [ ] スキルの導入と、動くアプリケーションのデプロイの違いを説明できる。
