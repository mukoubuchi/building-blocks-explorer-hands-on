# 演習

所要時間: 25 分（経過時間: 30–55 分）

Explorer で架空の文書アシスタントを題材に、候補の調査からスキルやモードの利用まで取り組みます。

課題 1 は調査と結果の記録、課題 2 はスキルやモードの追加・設定と利用まで行います。製品のデプロイは行いません。

## 課題 1: 関連する Building Blocks を探す {#exercise-1}

10 分

### ステップ 1: 候補を探す

新しい会話を始め、貼り付けます。

```text
架空の小売企業が、承認済みの商品資料や規程から、店舗担当者の質問に答えるアシスタントを検討している。
出典を示し、根拠がなければ回答が見つからないと伝える必要がある。

カタログ全体を対象に、このシナリオに関連する Building Blocks をすべて探す。
件数を限定せず、検索結果の続きがあれば取得し、重複を除いて一覧にする。
各 BB の用途、このシナリオとの関連、出典 URL を示す。
検索した範囲と未確認の範囲も示す。

確認質問は最大 2 つまでとし、1 回に 1 つずつ聞く。
調査のみ。インストール・デプロイは対象外。
```

質問された場合は、入力は架空の PDF/テキスト文書、利用者は店舗担当者とします。

### ステップ 2: 出典を確認する

候補の Building Block の README を開き、提供物と前提条件を確認します。リンクが開かなければ [Building Blocks の概要](https://github.com/ibm-self-serve-assets/building-blocks) から探し、確かめられない点は未確認とします。

### ステップ 3: 結果を記録する

```text
ワークスペース直下に Markdown ファイルを作成し、ここまでの調査結果を記録する。
「課題 1」の見出しで、業務課題、関連する BB の一覧、出典 URL、確認日、提供物、前提条件、検索範囲と未確認の範囲をまとめる。
確認した事実と仮定を分け、既存の記録は保持する。
```

## 課題 2: 最も関連する BB のスキルやモードを使う {#exercise-2}

15 分

### ステップ 1: 候補を探す

課題 1 の会話に続けて、以下を貼り付けます。

```text
先ほど見つけた BB の中から、このシナリオに最も関連する BB を 1 つ選び、理由を示す。
その BB に関連付けられたスキルやモードをカタログで探す。
架空の質問例や回答方針の検討に使うものを 1 つ提案し、BB との対応、用途、出典 URL、前提条件、追加・変更するファイルを示す。
追加後に試す作業も示す。
まだ追加・設定は行わないこと。
```

選んだ BB とスキルやモードの対応、公式の取得元、前提条件を確認します。利用できるものがない場合は、その理由を記録して講師へ相談します。

### ステップ 2: 選んだ候補を追加する

用途、前提条件、追加先、変更内容を確認してから、指示します。

```text
確認した候補を 1 つだけ、公式インストーラーでこの演習用ワークスペースへ追加・設定する。
既存設定を保持し、公式の取得元 URL、追加先、検証結果、利用を始める手順を示す。
追加の認証情報や外部サービスが必要になった場合は、作業を止めて知らせる。
製品のインストール・デプロイは対象外。
```

インストーラーの結果と追加されたファイルを確認し、Bob を再読み込みします。スキルの場合は `.bob/skills/` 配下の `SKILL.md` を確認し、モードの場合はモード選択欄から追加したモードを選びます。macOS・Windows とも Bob 上で確認します。

### ステップ 3: 追加した候補を使う

スキルの場合は名前を明示し、モードの場合は選択してから、課題 1 のシナリオを続けます。以下の「選んだ候補の名前」を置き換えて貼り付けます。

```text
「選んだ候補の名前」を使い、次の架空の商品資料から店舗担当者向けアシスタントの質問例と回答方針を検討する。

資料 A: 商品「トラベルマグ」の容量は 350 mL。食器洗い機は使用不可。
資料 B: 未使用の商品は購入後 30 日以内に返品可能。購入証明が必要。

回答できる質問を 2 つ、資料だけでは回答できない質問を 1 つ挙げる。
それぞれ回答例と出典、または回答できない理由を示す。
利用したスキルやモードの手順・観点も説明する。
選んだ BB と理由、追加したスキルやモード、取得元 URL、追加先、参照した手順、質問例と回答例、未完了の操作を課題 1 で作成した Markdown ファイルの「課題 2」へ追記する。
課題 1 を含む既存の記録は保持する。
コード実行と製品のデプロイは対象外。
```

出典と回答の対応、根拠がない場合の扱い、スキルやモードから使った手順・観点を確認します。追加しただけでなく、実際の回答に使われたことを確認します。

取得や利用に失敗した場合は、同じ BB に関連する別のスキルやモードを確認するか、講師へ相談して動作する環境の方とペアで続けます。未完了の操作はそのまま記録します。
