# 演習

所要時間: 30 分（経過時間: 25–55 分）

Explorer に質問を貼り付け、回答を得ます。

## 課題 1: データストリーミングについて聞く {#exercise-1}

以下を貼り付けて実行します。

```text
リアルタイムのデータストリーミングに使える Building Blocks はある？
```

## 課題 2: 金融業の顧客のセキュリティについて聞く {#exercise-2}

以下を貼り付けて実行します。

```text
セキュリティ要件が厳しい金融業の顧客に提案できる Building Blocks はある？
```

Bob が選択肢を示して尋ねてきたら、1 つ選びます。ファイルの作成やインストールの承認を求めてきたら「拒否」を選び、候補が示されたら次へ進みます。

## 課題 3: 製造業の顧客について聞く {#exercise-3}

以下を貼り付けて実行します。

```text
製造業の顧客に提案できる Building Blocks はある？
```

Bob が選択肢を示して尋ねてきたら、1 つ選びます。ファイルの作成やインストールの承認を求めてきたら「拒否」を選び、候補が示されたら次へ進みます。

## 追加の演習（uv が必要） {#extra}

Explorer のローカルインストーラーで、見つけた Building Blocks をこのワークスペースに入れ、構成図を描きます。Bob はインストーラーの操作のたびに承認を求めるので、内容を確かめて承認します。

!!! warning "uv の導入が必須"
    追加の演習には [uv の導入](preparation.md) が必須です。今はインストーラーが上流の不具合（[#262](https://github.com/ibm-self-serve-assets/building-blocks/issues/262)）で起動しないため、修正されるまで実行できません。

### 課題 4: スキルを入れる {#exercise-4}

以下を貼り付けて実行します。

```text
文書検索や RAG に使える Bob のスキルを 1 つ選び、このワークスペースにインストールして。入れたら、このワークスペースにあるスキルとモードを見せて。
```

`.bob/skills/` に、スキルのフォルダと `SKILL.md` ができたことを確かめます。

### 課題 5: モードを入れて切り替える {#exercise-5}

以下を貼り付けて実行します。

```text
データベースに自然言語で問い合わせる Bob のモードを 1 つ選び、このワークスペースにインストールして。
```

モードの選択欄に、入れたモードが出ることを確かめます。出ないときは、Bob を再読み込みします。入れたモードに切り替えられたら、Explorer のモードに戻します。

### 課題 6: 構成図を描く {#exercise-6}

以下を貼り付けて実行します。

```text
小売店で、商品と規約の文書から質問に答えるアシスタントを作りたい。使う Building Blocks を選び、構成図を描いて。
```

Bob が選択肢を示して尋ねてきたら、1 つ選びます。

ワークスペースに構成図の画像（PNG）ができ、開くと図が表示されることを確かめます。構成図を描くときは、図の内容が外部のサービス（mermaid.ink）に送られます。
