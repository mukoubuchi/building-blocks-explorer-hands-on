# 演習

所要時間: 15 分（経過時間: 15–30 分）

Explorer に質問を貼り付け、回答を得ます。

## 課題 1: データストリーミングについて聞く {#exercise-1}

以下を貼り付けて実行します。

```text
リアルタイムのデータストリーミングに使える Building Blocks はある？
```

## 課題 2: アクセス管理とシークレットについて聞く {#exercise-2}

以下を貼り付けて実行します。

```text
アクセス管理やシークレット管理に使える Building Blocks はある？
```

## 課題 3: 文書検索について聞く {#exercise-3}

以下を貼り付けて実行します。

```text
文書検索や RAG に使える Building Blocks はある？
```
