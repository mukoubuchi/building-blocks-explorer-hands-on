# Building Blocks Explorer の起動

所要時間：10 分・経過時間：20〜30 分

## ステップ 1：公式のワークスペースを取得する

[確認済みの Explorer ZIP](https://raw.githubusercontent.com/ibm-self-serve-assets/building-blocks/f721f5ec1915225ade62d8d0e780fe6b19aa58b8/explore-BBs/building-blocks-explorer.zip) をダウンロードします。このリンクは教材で確認した公式パッケージの版に固定しています。リモートのカタログは常に同じ内容とは限らず、更新されます。新しいパッケージは[上流の Explorer ガイド](https://github.com/ibm-self-serve-assets/building-blocks/tree/main/explore-BBs)を参照してください。

=== "macOS"

    Finder でダウンロードした ZIP をダブルクリックし、展開された `building-blocks-explorer` フォルダを確認します。`.bob` は通常は非表示です。確認する場合は `Command` + `Shift` + `.` で隠しファイルの表示を切り替えられます。

=== "Windows"

    エクスプローラーで ZIP を右クリックして「すべて展開」を選びます。圧縮ファイルを開いた画面ではなく、展開後のフォルダを使います。外側にフォルダが追加される場合があるので、`README.md` と `.bob` が入っている内側の `building-blocks-explorer` を選びます。

ワークスペースには `.bob/custom_modes.yaml` と `.bob/mcp.json` があります。演習用の新しいワークスペースを使い、顧客向けの作業と分けます。

## ステップ 2：Bob でフォルダを開く

Bob の「Open Folder（フォルダーを開く）」で、展開した `building-blocks-explorer` フォルダを選びます。信頼の確認が表示された場合は、自分が取得した公式パッケージであることを確認し、組織の方針に従ってください。

モードの選択欄から「🧱 IBM Building Blocks Explorer」を選びます。表示されない場合は、`.bob` のあるフォルダを開いているか確認して Bob を再読み込みします。選択欄の位置は Bob のバージョンによって異なる場合があります。

## ステップ 3：2 つの接続を確認する

Bob の MCP サーバーのパネルを開き、次の項目を確認します。

| サーバー | 役割 | 確認すること |
|---|---|---|
| `building-blocks` | ブロック、スキル、モード、文書のリモートカタログ | 接続済みで、カタログのツールを使える |
| `building-blocks-installer` | uvx で起動するローカルの補助プログラム | 接続済みである。初回は Python や依存パッケージを取得する場合がある |

公式 ZIP に接続設定が含まれています。この探索の演習で API キーの入力は求めません。個別の製品を動かす段階では、別途認証情報が必要になる場合があります。

Bob のチャットへ貼り付けます。

```text
私は Build Sales の初心者です。Building Blocks のカタログツールを使い、
AI、Data、Automation から、利用可能な候補を 1 つずつ紹介してください。
それぞれ名前、解決したい業務課題、出典のリンクを短く示してください。
インストールやデプロイは行わないでください。
```

会話に `list_building_blocks` などのカタログツールの実行と出典リンクがあることを確認します。文章だけの回答では接続の確認になりません。リンクを 1 つ開き、古い場合は[現在の概要](https://github.com/ibm-self-serve-assets/building-blocks)から README を探して差異を記録します。

## ステップ 4：記録の準備をする

講師から配布されたワークシートを使うか、このワークスペースへ `workshop-notes.md` を作り、課題の記録項目をコピーします。課題ごとに見出しを分けて残してください。ローカルへ保存しただけでは講師へ送信されません。

## うまく動かない場合

| 症状 | 次に行うこと |
|---|---|
| Explorer のモードが表示されない | 展開後の内側のフォルダと `.bob` を確認し、Bob を再読み込みする |
| インストーラーが uvx を見つけられない | uv／uvx を再確認し、Bob を完全に終了して起動し直す |
| 初回起動に時間がかかる | 最初の取得を待つ。停止した場合は MCP のエラーを確認する |
| カタログのツールが使えない | Bob を 1 回再起動する。講師に `.bob/mcp.json` のカタログ URL への接続確認を依頼する |
| 回答のリンクが開かない | 上流の現在の概要を使い、元の回答と参照し直した出典を両方記録する |
| 組織の制限で接続できない | 講師へ承認された方法を確認し、ペアで続ける |

!!! note "代替手段を使った場合の記録"
    インストーラーだけが使えない場合は、必須のカタログ演習を続け、追加のインストール課題は見送ります。カタログも使えない場合は、動作する方とペアになります。講師が README を使う演習へ切り替えることもできますが、その場合は「資料を読んだ代替演習」と記録します。Explorer の動作確認ができたことにはなりません。

- [ ] 正しいフォルダで Explorer のモードを選択した。
- [ ] カタログツールを使った回答が得られた。または、使った代替手段を記録した。
- [ ] 2 つのサーバーの役割を説明できる。
