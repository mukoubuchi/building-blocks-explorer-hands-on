# Documentation maintenance

English participant pages live directly under `docs/`; Japanese counterparts live under `docs/ja/`. Keep the five page names aligned with `mkdocs.yml` and `docs/javascripts/site-config.js`.

The CSS and JavaScript modules were inherited from `vector-search-hands-on` at commit `7776c6227da1c006f8107790003855dd5b23fa8f`, and its UI and search changes were synced at commit `6ca899a258f3937783929575c930e35f2ac36767`. Since October 27, 2026, the hands-on sites `building-blocks-explorer-hands-on`, `text2sql-hands-on`, `vault-secret-migrator-hands-on`, and `vector-search-hands-on` share the CSS and JavaScript files listed in `lib/shared_ui.py`, with the reference copies in `building-blocks-explorer-hands-on`. `lib/shared-ui.sha256` holds their SHA-256, and CI fails when a copy differs; change a shared file in the reference first, then copy it with `lib/shared_ui.py` (see its docstring). Only `docs/javascripts/site-config.js` belongs to each site: it sets `window.HandsOn.site` (the top-level page paths and the languages), which the shared scripts read. Styles that only one site uses live in a file of their own, listed after `extra.css` in that site's `mkdocs.yml` (for example, `vector-search.css`). `extra.css` imports the typography, navigation, code, components, language-switcher, palette, and fonts modules. Use Material theme variables for extensions. `search.js` relies on internals of Material 9.7.7 (the result count and the search highlights); recheck it whenever `mkdocs-material` in `setup/instructor/requirements.txt` changes.

Use `Step N:` / `ステップ N:` headings for the numbered rail. Use matching `macOS` and `Windows` tab labels across pages so selection stays linked. English is the default language; Japanese uses `/ja/`. No remote fonts or analytics are configured.

For build commands, see the root README. Run the strict MkDocs build and `lib/validate_docs.py`, then inspect both languages at desktop and mobile sizes. Check language links under the actual GitHub Pages project prefix, not only at `/`.

Japanese prose uses full-width parentheses, half-width colons followed by a space, and half-width spaces between Japanese and Latin text (including across inline code and link boundaries). Put spaces around arrows. Follow the source workshop's OS tabs, numbered step rails, modular assets, and bilingual layout. Keep lessons focused on actions, prompts, and completion checks. Markdown delimiters must render correctly with a CommonMark parser; punctuation stays outside bold delimiters. Code and URL syntax are exempt.
