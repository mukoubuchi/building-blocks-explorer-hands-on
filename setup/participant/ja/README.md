# Building Blocks Explorer Workshop Kit

This kit supports the Japanese edition of the 60-minute beginner Build Sales workshop. Bob must already be installed and usable; the workshop includes a recap and uv installation on macOS or Windows.

Open the Japanese `worksheet.md` in Bob or another Markdown editor and save a copy for your answers. Use the official Explorer download linked in the instructor-provided guide. This kit does not include the Explorer mode.

Complete both required exercises. The third challenge is optional and takes 5–10 additional minutes unless you finish early. Use fictional information only; no customer data, secrets, credentials, cloud account, or separate Python, Git, Node.js, or Docker setup is needed for the core workshop.

The kit does not submit your work. Share it only through the channel agreed with your instructor.
