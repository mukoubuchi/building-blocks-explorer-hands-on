# Building Blocks Explorer Workshop Kit

This kit is for a 60-minute beginner Build Sales workshop. Bob must already be installed and usable. The session starts with a Building Blocks recap and includes uv installation for macOS or Windows.

Open `worksheet.md` in Bob or another Markdown editor. Use a copy for your answers. Download the official Explorer workspace using the link in the workshop guide supplied by your instructor; this kit does not contain the Explorer mode.

Complete the two required exercises. The third challenge is optional and takes 5–10 additional minutes unless you finish early. Keep everything fictional. Do not provide customer data, secrets, or credentials.

The kit does not submit your work. Share the worksheet only through the channel agreed with your instructor. No cloud account or separate Python, Git, Node.js, or Docker installation is required for the core workshop.
